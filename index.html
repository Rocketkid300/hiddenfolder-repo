🔒 Hidden Folder

✓ Repo is live

A passcode-protected "Hidden" folder at the end of the App Library for Dopamine (rootless, iOS 15–16). Turn on Hide Mode and tap any Home Screen app once to hide it.

📲 Install in Sileo

  1. Open Sileo → Sources → ⨁
  2. Add this repo URL: https://rocketkid300.github.io/hiddenfolder-repo/
  3. It's unsigned — tap Add Anyway when warned
  4. Install Hidden Folder (it will respring)

⚙️ First-time setup

  1. Open Settings → Hidden Folder
  2. Set a passcode (4–8 digits)
  3. Turn on Enable + Hide Mode
  4. App Library → tap the 🔒 Hidden pod → enter your code
  5. Hide: tap any Home Screen icon once (while Hide Mode is on)
  6. Unhide: long-press an app inside the Hidden folder

Current version 1.0.0  ·  Architecture iphoneos-arm64  ·  iOS ≥ 15.0
