📲 Install in Sileo

  1. Open Sileo → Sources → ⨁
  2. Add this repo URL: https://rocketkid300.github.io/hiddenfolder-repo/
  3. It's unsigned — tap Add Anyway when warned
  4. Install Hidden Folder (it will respring)

📱 New: install the Hidden Vault app

Don't want to mess with tweaks? Hidden Vault is a plain app — install it, and it sits right in your App Library as a normal pod (dark locked-folder card, labeled "Hidden"), just like the iOS 18 "Suggested / Recently Added" cards.

  1. In Sileo install Hidden Vault (com.bigpickle.hiddenvault)
  2. If the icon doesn't show, respring once
  3. Open it → Set Passcode (⚙️) → ➕ add the apps you want inside
  4. Unlock it the Apple way: Face ID / Touch ID / your iPhone passcode — or a custom 4-digit code
  5. Everything you added opens only from the passcode-gated vault — it re-locks itself every time

No substrate, no ellekit, no oldabi — just an app. The tweak version is optional and shares the same passcode.

⚙️ First-time setup (tweak version, all inside the folder)

  1. Open the App Library → tap the 🔒 Hidden pod at the end
  2. Tap the ⚙️ gear (top left) → Set Passcode → enter a 4-digit code twice
  3. Flip the Hide Mode switch ON
  4. Hide: tap any Home Screen app once (while Hide Mode is on)
  5. Unhide: long-press an app inside the Hidden folder

No Settings-app page needed — everything lives in the folder itself.
